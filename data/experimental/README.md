# Experimental data

Content in this directory supports research and pipeline testing. It is not an operational catalog or production training data.

## Ranking

See [ranking/README.md](ranking/README.md). The current dataset is derived from OSM, uses six analyst-assumed intents, and has weak rule-generated labels. Results indicate whether a model can learn the labeling rules; they do not represent real user preferences.

## Flood-report experiment

flood_training_weak_labels.csv is an experiment about the appearance of public reports. It includes assumed negative labels generated by sampling. It does not predict physical flooding, verify that a road was dry, or qualify as a flood-risk model for the planner.

Do not use these datasets to make production or “verified” claims. Keep estimated values and provenance visible.
