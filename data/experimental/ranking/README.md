# Weak-label experience-ranking experiment

## Dataset

ranking_candidates_labeled.csv contains 3,828 rows: 638 OSM place candidates crossed with six analyst-assumed intent profiles. The grades are generated by categorization/scoring rules, not by real travelers. Some prices, durations, and ETAs are estimated; review estimation_parameters.json and source_audit.json.

The dataset has no verified slot, capacity, planner decision, or operational status evidence. Do not duplicate queries to inflate the sample. The evaluation keeps POIs separate between splits, but it does not measure generalization to new intents.

## Existing benchmark

colab-results/ contains the supplied benchmark metadata, metrics, schema, preprocessing, model card, test predictions, and validation comparison. Interpret results only in the context of the weak labels. They are not evidence of recommendation quality for real users.

The API's default ranking method is the rule baseline. The bootstrap artifact is not production-eligible. Use the [benchmark guide](../../../docs/experience-ranker-benchmark.md) to reproduce the experiment and record dependency versions and hashes.
